# Главная страница СПК-Урал — концепт редизайна

Адаптивная главная страница на чистом HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются.

## Как открыть

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для локального сервера можно запустить из папки проекта:

   ```bash
   python -m http.server 8000
   ```

   Затем откройте `http://localhost:8000`.

## Структура

- `index.html` — разметка главной страницы.
- `assets/css/styles.css` — стили, адаптивная сетка и состояния компонентов.
- `assets/js/main.js` — мобильное меню, модальное окно и форма заявки.
- `assets/img/hero-products.svg` — локальная SVG-иллюстрация первого экрана.

## Важные замечания перед публикацией

- Карточки каталога ведут на соответствующие страницы действующего сайта `ural-umc.ru`.
- Изображения категорий загружаются с действующего домена. Перед переносом на другой хостинг их лучше скачать и положить в `assets/img`, чтобы новый сайт не зависел от старого хранилища изображений.
- Форма заявки пока открывает почтовое приложение и подготавливает письмо на `sales@ural-umc.ru`. Для полноценной отправки без почтового клиента нужно подключить серверный обработчик или CRM.
- Перед заменой действующего сайта сохраните резервную копию файлов и базы данных, проверьте все URL и согласуйте тексты с владельцем компании.
- Контактные данные и разделы взяты с действующего сайта на момент подготовки макета; перед публикацией их следует подтвердить у владельца.
